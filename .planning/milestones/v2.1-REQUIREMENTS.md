# Requirements Archive: v2.1 Meeting Engine Polish

**Defined:** 2026-03-17
**Completed:** 2026-03-17
**Status:** All 28 requirements verified DONE

## Meeting Engine

- [x] **MEET-01**: When a meeting concludes, a task is auto-created in the task board with meeting topic as title and outcome summary as description
- [x] **MEET-02**: Meeting-created tasks include a reference back to the source meeting ID
- [x] **MEET-03**: Collaborator suggestions panel displays top-5 partners ranked by the 5-factor selection algorithm with score breakdown
- [x] **MEET-04**: Collaborator suggestion scores update after each meeting based on latest trust data
- [x] **MEET-05**: Meeting scheduler supports configurable recurring intervals per agent (not just random initiation)
- [x] **MEET-06**: Scheduled meetings respect agent availability (skip agents currently in meetings or busy)
- [x] **MEET-07**: Meeting analytics page renders meeting frequency over time as a recharts chart
- [x] **MEET-08**: Meeting analytics shows per-agent stats: meeting count, average duration, and trust delta
- [x] **MEET-09**: Conversation quality scoring evaluates each meeting transcript via LLM and stores a score (0.0-1.0)
- [x] **MEET-10**: Quality scores visible in meeting history list and individual meeting detail view

## Visual Quality

- [x] **VIZQ-01**: Each agent has a deterministic color derived from agent ID, consistent across desk marker, speech bubble, name label, and canvas indicator
- [x] **VIZQ-02**: Speech bubbles use dark theme (dark background, light text) matching the application palette
- [x] **VIZQ-03**: Speech bubbles animate out (fade + slide) when conversation ends instead of instant removal
- [x] **VIZQ-04**: Meeting detail panel slides in/out with spring-physics CSS transitions
- [x] **VIZQ-05**: Agent movement on office canvas uses CSS transform transitions instead of requestAnimationFrame re-renders
- [x] **VIZQ-06**: Hovering an agent on the office canvas shows a tooltip with name, role, status, and active meeting info
- [x] **VIZQ-07**: Force-directed trust network graph renders agent nodes connected by trust-weighted edges as pure SVG (no D3)
- [x] **VIZQ-08**: Trust graph stabilizes within 2 seconds for 20 agents
- [x] **VIZQ-09**: Floor tile grid rendered as single CSS background-image repeat instead of 384 individual DOM nodes
- [x] **VIZQ-10**: Idle agents display at reduced opacity compared to active/meeting agents, updating in real-time via SSE

## Testing

- [x] **MTST-01**: Unit tests cover meeting state machine transitions with property-based invariants
- [x] **MTST-02**: Unit tests verify 5-factor partner selection algorithm correctness and edge cases
- [x] **MTST-03**: Unit tests cover trust score update logic including bounds and decay
- [x] **MTST-04**: Integration tests use recorded LLM responses to verify full conversation flow without live API calls
- [x] **MTST-05**: Integration tests validate quality scoring produces expected scores for known transcripts
- [x] **MTST-06**: E2E tests verify SSE delivers meeting lifecycle events to connected clients
- [x] **MTST-07**: E2E tests verify meeting panel renders participants and speech bubbles correctly
- [x] **MTST-08**: E2E tests verify canvas markers reflect agent position updates
